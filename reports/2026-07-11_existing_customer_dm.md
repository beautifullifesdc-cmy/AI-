# 既存のお客様向けDM — 近況報告＋依頼＋サロン紹介のお願い

**作成日**: 2026-07-11
**対象**: 写真会等で知り合った既存のお客様（顧客リストではなく個別の知人ベース）
**目的**: ①Beautiful Lifeの活動を知ってもらう ②あわよくば依頼につなげる ③通っているトリミングサロンへの紹介をお願いする
**トーン**: 営業DMとは別物。すでに関係がある相手への"近況報告"として書く

---

## 0. 設計の考え方

営業DM（サロン向け）とは全く違うトーンにするのがポイント。
- 初対面の営業文句（「はじめまして」「ご連絡させていただきました」）は使わない
- 「久しぶり／お世話になってます」の温度感からスタート
- お願いごとは2つ入れるが、押し付けがましくならないよう「もしよかったら」で軽くする
- 依頼の勧誘とサロン紹介、両方を1通に自然に入れる（別々に送ると重たい）

---

## 1. メインテンプレート

```
〇〇さん、こんにちは！Beautiful Lifeです😊
以前、写真撮影でお世話になりました。お元気にされていますか？

実はあれからBeautiful Lifeとして本格的に活動を始めていて、
最近はトリミングサロンさんの撮影などもさせてもらっています。

もしよければ、また〇〇ちゃん（愛犬・愛猫の名前）の様子も
撮らせてもらえたら嬉しいです。前回とはまた違った形で
残せるものも増えてきました。

あと、もう一つお願いがあって…
〇〇さんがいつも通われているトリミングサロンさんって、
もしよろしければご紹介いただけたりしませんか?🙏
サロンさん向けに、店内やわんちゃんの様子を動画で
撮影・制作するサービスをしていて、力になれたら嬉しいなと思っています。

お時間あるときにでも、返信もらえたら嬉しいです！
突然のご連絡失礼しました。
```

---

## 2. 少し短縮したバージョン（テンポよく送りたい相手向け）

```
〇〇さん、こんにちは！Beautiful Lifeです😊
写真撮影ではお世話になりました！お元気ですか？

あれからBeautiful Lifeの活動を広げていて、
トリミングサロンさんの撮影なんかもやらせてもらってます。

またよければ〇〇ちゃんの撮影もさせてもらえたら嬉しいです。

あと、もし差し支えなければ、〇〇さんが通われている
トリミングサロンさんをご紹介いただけたりしませんか?🙏
サロン向けに動画制作のお手伝いをしていて、力になれたらと思っています。

もしよければ返信もらえると嬉しいです！
```

---

## 3. サロン紹介だけをお願いする場合（撮影の勧誘なし・シンプル版）

すでに何度もやり取りがあり、撮影の話は不要な相手向け。

```
〇〇さん、こんにちは！お元気ですか？
Beautiful Lifeです、いつもありがとうございます😊

一つお願いがあって連絡しました。
〇〇さんがいつも通われているトリミングサロンさんを、
もしよろしければご紹介いただけないかなと思っていて…🙏

サロンさん向けに、店内やわんちゃんの様子を動画で
撮影・制作するサービスをしていて、お力になれたら嬉しいです。

もし可能そうであれば、サロンさんのお名前だけでも
教えてもらえると助かります！よろしくお願いします。
```

---

## 4. 送り方のポイント

- 〇〇さん・〇〇ちゃんの部分は必ず個別にカスタム（名前を間違えないように）
- 一斉送信ではなく、1人ずつ個別のトーンで送るのが望ましい（関係性があるからこそ効く）
- サンプル動画のリンクは基本不要（すでに実物を知っている相手のため）。
  ただし「サロンさんに紹介する材料が欲しい」と言われたら下記を添える：
  ```
  ちなみに実際に撮影したサンプルはこちらです👇
  ▶ https://youtu.be/71vGjnKQV-M
  もしサロンさんに見せていただけたら嬉しいです！
  ```
- 紹介してもらえたら、必ず本人にもお礼を伝える（次につながる）
