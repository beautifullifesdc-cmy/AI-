# 既存のお客様向けDM — 2ステップ構成（サンプル共有 → 会話が広がったら依頼）

**作成日**: 2026-07-11（改訂）
**対象**: 写真会等で知り合った既存のお客様（個別の知人ベース）
**目的**: ①Beautiful Lifeの活動を知ってもらう ②あわよくば依頼につなげる ③通っているトリミングサロンへの紹介をお願いする
**トーン**: 営業DMとは別物。すでに関係がある相手への"近況報告"として書く

---

## 0. 設計を変更した理由

前版は「1通目からお願いごとを2つ並べる」構成になっていて、営業感が強すぎた。
正しい順番はこう：

```
① まずサンプルを見てもらう（お願いなし・見てほしいだけ）
      ↓
② 「いいね」「すごい」などリアクションが来る
      ↓
③ その会話の流れの中で、自然に撮影やサロン紹介の話に広げる
```

**お願いは最初に置くものではなく、会話が生まれた後に出すもの。** 1通目は徹底的に軽く。

---

## 1. 【1通目】サンプル共有だけ（お願いなし）

```
〇〇さん、こんにちは！Beautiful Lifeです😊
お元気にされていますか？

実はあれからBeautiful Lifeとして活動を広げていて、
最近撮影したものをふと〇〇さんにも見てほしくなって連絡しました。

▶ https://youtu.be/71vGjnKQV-M

お時間あるときにでも見てもらえたら嬉しいです！
突然のご連絡失礼しました〜
```

→ これだけ。お願いは一切書かない。「見てほしい」という気持ちだけを伝える。

---

## 2. 【2通目】感想が来たら（会話の流れで自然に広げる）

相手の反応に応じて、以下のいずれかを自然に続ける。**テンプレそのまま貼るのではなく、相手の言葉を受けてから繋げる。**

### パターンA：好意的な反応が来たら → 撮影の話に広げる

```
ありがとう！そう言ってもらえると嬉しい😊

もしよかったら、また〇〇ちゃんの様子も
撮らせてもらえたら嬉しいな。前より色々できることも増えたから、
また違った形で残せると思う！
```

### パターンB：会話が続いたら → サロン紹介を軽く聞いてみる

```
そうそう、実はサロンさん向けにも
こういう動画を作らせてもらうことが増えてきてて。

〇〇さんが今通ってるトリミングサロンさんって、
もしよかったら今度紹介してもらえたりする？🙏
力になれたら嬉しいなと思って。
```

→ AとBは同じ返信の中に続けて書いてもいいし、別のタイミングに分けてもいい。
　 大事なのは「会話の中の一部」として出すこと。最初から用件として並べない。

---

## 3. もし1通目に反応がない場合（1週間後くらい）

催促にならないよう、軽く。

```
〇〇さん、お元気ですか？😊
前に送った動画、もし時間あれば見てもらえたら嬉しいです！
▶ https://youtu.be/71vGjnKQV-M
```

---

## 4. 送り方のポイント

- 1通目は「見てほしい」以外の情報を極力入れない。お願いごとゼロ
- 〇〇さん・〇〇ちゃんは必ず個別カスタム
- 一斉送信ではなく、1人ずつ個別に送る
- 2通目は**相手の反応を見てから手で書く**のが理想（テンプレの丸コピペだと違和感が出やすい）
- サロン紹介をしてもらえたら、必ず本人にお礼を伝える
