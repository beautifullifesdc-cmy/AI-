# Beautiful Life合同会社 コーポレートサイト 制作依頼

## 目的

Beautiful Life合同会社の公式コーポレートサイトを制作してください。
このサイトは、銀行・取引先・提携先企業が会社の信頼性を確認するための「会社としての顔」です。
サービスLP（beautifullife-movie.netlify.app）とは役割が異なり、
**フォーマルで信頼感のあるトーン**を基調としつつ、適度な動きのあるモダンな企業サイトを目指します。

---

## 技術スタック

```
フレームワーク： Next.js（App Router, TypeScript）
スタイリング　： Tailwind CSS
アニメーション： Framer Motion（スクロール連動フェードイン、ホバーエフェクト等）
フォント　　　： Google Fonts「Noto Serif JP」（見出し）＋「Noto Sans JP」（本文）
```

- ページ遷移・要素の出現には Framer Motion で控えめなアニメーションを入れる（例：スクロールで下から浮かび上がるフェードイン、ボタンホバー時の拡大・色変化）
- 派手な演出は避け、「信頼感のあるモダンさ」を意識する

## 各ページの内容

### トップページ（/）

```
Section 1: ヒーロー
  会社名ロゴ＋キャッチコピー
  「ペットと人の、美しい瞬間を。」
  スクロールで下にフェードイン

Section 2: 事業紹介（3カード、強弱をつける）
  Beautiful Life（映像制作事業） → 大きめのカード、メインビジュアルあり
  DINO（ペットフォトスタジオ事業） → 大きめのカード、メインビジュアルあり、
    「OPEN PREPARING」のようなバッジを添える（オープン前のため）
  セールスプロモーション事業 → 小さめのシンプルなカード、画像なしでも可

Section 3: 会社概要の要約（抜粋）
  商号・所在地・代表者・設立日を簡潔に表示し、「会社概要を見る」ボタンで
  /company/profile へ

Section 4: ニュース最新3件
  まだ記事がなければ「準備中」のプレースホルダー表示

Section 5: お問い合わせCTA
  アクセントカラーの背景で強調
  「お問い合わせはこちら」ボタン → /contact
```

## 注意事項

- 文中に「AI」「人工知能」「自動生成」などの言葉は一切使わない
- 料金・価格の具体的な記載は各事業ページでは行わない（個別見積もり対応とする）
- 画像は仮素材でOK。後で差し替えられるようファイル名・コンポーネント構造をわかりやすくする
- レスポンシブ対応必須（スマートフォンでの閲覧を最優先に）
- ドロップダウンメニュー（会社情報）はスマホではタップで開閉するアコーディオン形式にする
