## Beautiful Life の本当のポジション（定義）

```
❌ 動画制作会社
❌ SNS運用代行
❌ ペット写真家

⭕ 「ペット業界特化 × 月額訪問型 × 企業文化の映像資産化パートナー」
```

### なぜこのポジションが強いか

| 軸 | 一般の動画制作会社 | Beautiful Life |
|----|-----------------|----------------|
| 売るもの | 動画1本 | 文化・価値観の可視化 |
| 関係性 | 単発取引 | 継続パートナー |
| 顧客の課題認識 | 「動画が欲しい」 | 「集客・採用・ブランドをどうにかしたい」 |
| 単価 | 5〜30万円/本 | 月額3〜8万円（積み上がる） |
| 競合 | 無数にいる | ほぼいない（ペット業界特化は空白） |
| 価格競争 | 巻き込まれる | 巻き込まれない |

## 事業の構造（3層モデル）

```
【Layer 3：最終価値】
企業文化アーカイブ・事業承継・採用ブランディング
"オーナーの想い・スタッフの人柄・店の歴史"を資産として残す
       ↑ 信頼関係が積み上がった後に自然に広がる

【Layer 2：中間価値】
採用動画・スタッフインタビュー・店舗PR・ブランドムービー
"なぜこの仕事をしているか"を映像化
       ↑ 月額継続で信頼が生まれた後にアップセル

【Layer 1：入口】
月額SNSコンテンツパッケージ
"月1回の訪問で1ヶ月分の投稿素材を納品"
       ↑ 今ここを作っている（ANELA・猫カフェ）
```

## 競合分析

### 競合4分類と Beautiful Life の位置づけ

```
① 動画制作会社（Buddy Movie等）
   → 高単価・1本納品・継続弱い・小規模店には高い
   Beautiful Lifeとの違い：「継続月額」「SNS特化」「ペット業界のみ」

② SNS運用代行（Media Quest等）
   → 撮影しない・テンプレ運用・地域感なし
   Beautiful Lifeとの違い：「実際に撮影に来る」「シネマティック品質」

③ フリーランスクリエイター
   → 撮るだけ・編集するだけ・安い
   Beautiful Lifeとの違い：「戦略提案できる」「採用・ブランディングまで繋げる」

④ ペット業界専門会社
   → ほぼ存在しない（HP制作・EC止まり）
   ← ここが最大の空白地帯
```

### ポジショニングマップ

```
          高単価
            ↑
            │
動画制作会社 ─────────────────── Beautiful Life（目指す位置）
            │                      ↗
一般的 ─────┼─────────────────── 業界特化
            │                ↗
フリーランス ─────────────────────
            │
            ↓
          低単価
```

**Beautiful Lifeは「高単価 × ペット業界特化」の空白地帯を取りに行く。**

## Jobs からオーナーへの一言

> このビジョンは、オーナーが家業（炉メーカー）で感じた
> 「技術だけでなく文化・価値観を残したい」という原体験と一致している。
>
> ペット事業者も同じだ。
> オーナーたちは「なぜこの仕事をしているか」を誰かに伝えたいが、
> 言葉にする方法を持っていない。
>
> Beautiful Lifeはその橋渡しをする会社だ。
> 「動画を作る会社」と思った瞬間に競合だらけになる。
> 「文化を可視化するパートナー」と思えば、競合はほぼいない。

## ▼ 潜在機会

1. **ペット業界でこのポジションを確立した会社は日本に存在しない**——先行者利益が取れる
2. **月額モデルが10社になれば個人事業として成立する売上になる**——¥500,000/月
3. **採用動画・事業承継アーカイブは単価が高く、競合が少ない**——Layer 2〜3に進めた時の伸びしろが大きい
4. **ペット業界のオーナーは「この人に頼みたい」という信頼で選ぶ**——シネマティック品質＋継続関係＝最強の参入障壁

## ▼ 潜在リスク

1. **ビジョンが大きくなりすぎて今の行動がブレるリスク**——今月は「ANELA・猫カフェのサンプルを完成させること」だけ
2. **月額モデルは解約されると収益が一気に落ちる**——品質と関係性の維持が命
3. **撮影・編集・営業を1人でやるには上限がある**——Phase 2で外注・パートナー戦略が必要
