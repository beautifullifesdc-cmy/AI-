## 2. 受注ゼロの構造を分解する

これまでの活動を振り返ると：

```
サロン提携：複数獲得（ポスター設置・IG投稿・HP掲載）
ブリーダー提携：1件獲得（ポスター設置）
　→ 「提携」は取れている
　→ しかし「提携先経由でのお客様からの実際の撮影予約」がまだゼロ
```

これは営業チャネルの問題ではなく、**「提携先に置いたポスター・告知を見た飼い主が、
実際に申し込むまでの導線」がまだ弱い**可能性が高い。

### 確認すべきこと（8/27までに）
- [ ] 設置したポスターのQRコード・URLは実際に機能しているか（自分でスマホで読み取ってみる）
- [ ] 申し込み先（LINE・フォーム等）は迷わずたどり着けるか
- [ ] 各提携先のスタッフが、口頭でもお客様に一言案内してくれているか（ポスターだけでは弱い）

## 3. 残り11日間のスケジュール設計

### まるまる動ける日2日の使い方（最重要）

新規開拓ではなく、**「すでにある提携先を成約に変える」ことに全振り**するのが最も費用対効果が高い。

```
【フル稼働日①】既存提携先の"実質稼働率"を上げる
  - 各提携先（サロン・ブリーダー）を再訪問 or 電話
  - スタッフへの口頭案内をお願いする（「一言添えていただくだけで結構です」）
  - 店内ポスターの視認性を再チェック（レジ横・目線の高さにあるか等）
  - 可能なら、その場で1件でも撮影の約束を取り付ける

【フル稼働日②】8/27訪問の準備＋新規テレアポ集中デー
  - 3店舗目訪問の持参物・提案内容を仕上げる
  - ブリーダー・ペットショップリスト（109件）の電話番号確認済み先へ集中架電
  - 訪問先の近隣で飛び込み訪問も組み合わせる（転換率5%の実績チャネル）
```

### リモートワークの合間（毎日・隙間時間）

```
□ 電話：1日3〜5件を目安に（隙間時間で無理なく）
□ Instagram：週3投稿の固定フォーマットを維持
   月：Before/After　水：舞台裏　金：作品系
□ DM/HPフォーム：残りリストへ継続送信
```
