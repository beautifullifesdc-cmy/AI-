# 本日8時間 作業計画｜2人分担版

**作成日**: 2026-04-30  
**作成者**: Jobs (CEO)  
**前提**: 2名で8時間・インスタ充実＋土曜訪問準備

---

## 大原則

> **「今日終わらせること」だけに集中する。考えるな、動け。**

迷ったらこの3つに戻る:
1. Instagramに今日7本分の投稿をスケジュール登録する
2. 土曜の訪問で使う資料・台本を完成させる
3. Be StyleにDMを送る

---

## 役割分担

| 担当 | 役割 | 得意な作業 |
|------|------|-----------|
| **Person A（オーナー）** | クリエイティブ担当 | Canvaデザイン・動画編集・判断が必要な作業 |
| **Person B（サポート）** | リサーチ・準備担当 | 調査・テキスト整理・印刷・ツール設定 |

## ⏰ 8時間タイムテーブル

---

### 🕐 Hour 1（0:00〜1:00）：環境セットアップ ← 今すぐ始める

**Person A と Person B、同時進行**

#### Person A の作業（30分）
```
□ Instagramをプロアカウントに切り替え
  → Instagram → プロフィール編集 → プロアカウントに切り替え
  → 「クリエイター」→ カテゴリ:「写真/ビデオサービス」

□ CanvaにInstagramを連携
  → Canva → 任意のデザイン → 右上「共有」→「もっと見る」→「Instagram」
  → サインインして連携完了

□ Canvaでブランドカラーを登録（一度やれば永久に使える）
  → Canvaの「ブランドキット」→ 以下を登録
  　 ゴールド: #C9A84C
  　 ホワイト: #FAF7F0
  　 ブラウン: #3D2B1F
```

#### Person B の作業（60分）
```
□ reports/2026-04-30_instagram_ready_to_post.md を開く
  → 月〜日の全キャプションをテキストファイルにコピーして保存
  → 投稿ごとにファイル分割（月.txt、火.txt... 日.txt）

□ Unsplashで犬写真を5枚ダウンロード（火曜・金曜用）
  → unsplash.com → 検索「fluffy dog portrait」「dog grooming」
  → ウォームトーン・自然光のものを選ぶ

□ Be Styleの Instagramアカウントを特定
  → Instagram検索:「be_style」「be style 瀬谷」「大島亮 トリマー」
  → アカウントURLをメモ
  → フォロー＋最新投稿に3件いいね
```

---

### 🕑 Hour 2（1:00〜2:00）：Canvaデザイン① 月・火の投稿を作る

#### Person A の作業
```
【月曜投稿】Beautiful Lifeとは？ イラスト（45分）
→ Canva → Instagram投稿（1080×1080）
→ テンプレート検索:「ミニマル」→ シンプルなものを選ぶ
→ 背景: #FAF7F0
→ 中央大テキスト:「ペットの"美しさ"を、映像に残す。」
→ 下部小テキスト:「トリミングサロン専門 シネマティック動画×SNS支援」
→ Canva素材から犬 or カメラのシンプルアイコンを追加
→ 右上「共有」→「Instagram」→ 月曜の日時を設定 → 予約
```

#### Person B の作業
```
【火曜投稿の準備】
→ Unsplashでダウンロードした写真をCanvaにアップロード
→ 火曜のキャプションを.txtファイルから開いておく
→ ハッシュタグをメモ帳にコピーして準備

【同時進行】Meta Business Suite の設定
→ business.facebook.com にアクセス
→ Facebookアカウントでログイン → Instagramを連携
→ 「コンテンツ」タブを確認しておく
```

### 🕒 Hour 3（2:00〜3:00）：Canvaデザイン② 火・水の投稿を作る

#### Person A の作業
```
【火曜投稿】犬写真＋キャプション（15分）
→ Personが用意した写真をCanvaで開く
→ 下部にゴールドの帯（透過50%）→ キャプション1行を追加
→ 「@beautifullife.movie」を右下に小さく
→ 火曜の日時で予約投稿

【水曜投稿】テキストリール（30分）← 最重要
→ CapCut（スマホアプリ）を使う
→ 「テンプレート」→ 縦型シネマティック系を選択
→ reports/2026-04-30_instagram_ready_to_post.md のスライド10枚を入力
→ 「サウンド」→ ↗マーク付きのトレンド曲を選択
→ エクスポート → Instagramに直接投稿（水曜の日時で予約）
```

```

  　□ Instagramの投稿スタイル・フォロワー数

→ reports/2026-04-30_aggressive_marketer_be_style_approach.md を読む

#### Person A と Person B、一緒に作業

```

Person A = サロンオーナー役（大島さん）
Person B = Beautiful Life役

台本（5分版）:
─────────────────
「突然お邪魔してすみません。
 Beautiful Lifeという映像制作の [名前] と申します。
 Instagramを拝見して、技術がすごく伝わってきたので来ました。
 2分だけよろしいですか？」

（サンプル動画または今日作ったリールを見せる）

「これが私たちが作れる映像です。
 こういうクオリティで、大島さんの仕事を残したいんです。」

（反応を見て）
「今、モニターを3サロン限定で募集しています。
 通常7〜8万円のところ、初回は¥20,000でご提供できます。
 1本だけ試してみませんか？」
─────────────────

→ 3回練習する
→ 断られたときの返し方も練習:
  「そうですよね。もしよろしければ、
   名刺だけ置かせていただいてもいいですか？」

## 土曜訪問について（確認事項）

Jobs から確認:  
**土曜の訪問は「撮影（保護犬 or ドッグトレーナー）」か「営業（Be Style等）」か？**

- 撮影の場合 → Operations のフロー・機材チェックリストの準備が必要
- 営業の場合 → 今日の台本練習と提案書で十分

どちらかを教えてもらえれば、Hour 7 の内容を差し替える。
