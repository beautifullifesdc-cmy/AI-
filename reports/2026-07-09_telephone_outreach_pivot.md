## 0. 現状の率直な診断

- IG DM 30件（day1: 15件／day2: 15件）→ **返信0件**
- リスト90件のうち「small（個人系）× Instagramあり × 未送信」は実質**1件のみ**（しかも競合注意店）
  → **既存リストのDM在庫はほぼ枯渇**。同じやり方を続けても件数が増やせない
- Instagramの実フォロワー数（100〜200人という条件）は、こちらの環境からは直接確認できない
  （ログインなしでのInstagramアクセスは技術的にブロックされる）
- 「2026年新規開業サロン」も検索したが、具体的な実在店舗情報は出てこなかった
  （検索結果は開業ノウハウ記事のみで、実店舗名を作り出すことは避けた）

**→ だから今回は、実在確認済みの手持ちリスト90件の中から「Instagramを持たない個人サロン34件」を新チャネル（電話・HP問い合わせフォーム）で狙う。**

これは条件的にも理にかなっている：
- SNSに力を入れていない＝小規模・開業したて・手が回っていない可能性が高い
- IG DMより電話の方が、担当者に直接届く（DMは埋もれるが電話は無視できない）
- チャネルを分けることで「IGで反応がない層」と「電話なら反応する層」を切り分けられる

## 2. テレアポ トークスクリプト

### オープニング（最初の10秒が勝負）

```
お世話になります。Beautiful Life（ビューティフルライフ）と申します、
突然のお電話失礼いたします。

トリミングサロンさま向けに、施術シーンや店舗の様子を
映像で撮影・制作するサービスを行っておりまして、
少しだけお時間よろしいでしょうか？（30秒ほどで結構です）
```

### 相手が「はい」と言ったら（要件を簡潔に）

```
ありがとうございます。

私たちは、サロンさまにお伺いして、わんちゃんたちの様子や
店内の雰囲気を"映画のような映像"として撮影し、
そのままSNSに使える形で納品するサービスをしています。

実際に撮影したサンプル動画がありまして、
もしよろしければ、お店のメールかLINEにURLをお送りしても
よろしいでしょうか？
```

→ **電話の目的はここまで。契約や詳細説明はしない。**
「サンプルを送る許可」をもらえたら十分成功。

```
お電話でお話しした Beautiful Life です。
サンプル動画はこちらです。
▶ https://youtu.be/71vGjnKQV-M

ご覧いただいて、もしご興味あれば、今月中に一度

```

```
もし今後ご興味持たれましたら、いつでもご連絡ください。
失礼いたします。
```

→ 無理に食い下がらない。次に電話する店で印象を悪くしない方が大事。

## 4. IG DMチャネルについて（並行継続）

IG DMが完全にダメというわけではなく、まだ**3〜5日は様子を見る価値がある**（day1分は7/10〜7/12にフォローアップ予定）。
ただし新規追加分の在庫が尽きたので、以下も検討候補：

- **返信率が低い原因の仮説**：①新規アカウントでリーチ制限がかかっている ②DM文が長い ③タイミング（担当者が見る時間帯とズレている）
- **改善案**：DM前に対象サロンの投稿に「いいね」やコメントを1〜2回してから送ると、開封率が上がりやすい
- フォロワー数のリアルタイム確認は、Instagramアプリ上で直接見る必要がある（このツールからは不可）
