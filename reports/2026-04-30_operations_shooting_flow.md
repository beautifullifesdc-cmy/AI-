## 2名体制 撮影当日フロー（標準）

### 【前日】
- [ ] サロンオーナーに翌日の確認連絡（駐車場・スペース・犬のコンディション）
- [ ] 機材フルチェック（バッテリー充電・SDカード空き確認）
- [ ] ショットリスト印刷 or スマホに保存
- [ ] BGM候補を3曲選定・ダウンロード

### 【当日 撮影1時間前】
- [ ] 機材一式を車/バッグに積み込み
- [ ] カメラマン・ハンドラー、現地集合時間を確認
- [ ] サロンへの到着予定時刻を再連絡

### 【到着〜撮影準備（20分）】
- [ ] サロンオーナーへの挨拶・最終確認（今日の犬の状態・撮影NGシーンの確認）
- [ ] 撮影スペースの確認・照明チェック
- [ ] カメラ設定（露出・ホワイトバランス・フレームレート）
- [ ] ハンドラーが犬と挨拶・信頼関係の構築開始

### 【撮影中の役割分担】

| 役割 | 担当 | 主な行動 |
|------|------|---------|
| カメラマン | オーナー | 撮影に専念。ショットリスト通りに進める |
| ハンドラー | 同行者 | 犬が安全でいるか常に監視・誘導。犬をカメラ方向へ向ける補助 |
| サロン業務 | トリマー | トリミングに専念（妨げない） |

**絶対ルール（撮影中）:**
- 犬がストレスサインを出したら即撮影中断
- トリマーの動きを止めない・邪魔しない
- サロンの他の顧客（犬・飼い主）をフレームに入れない（プライバシー）

### 【撮影終了後（15分）】
- [ ] 撮影した素材をその場で一部確認・オーナーに見せる（期待値UP）
- [ ] 納品日程の再確認（撮影から5営業日以内）
- [ ] SNSタグ付け・二次利用の許可確認
- [ ] お礼の言葉 + 次回の提案をさりげなく

## 機材チェックリスト

### 必須機材
- [ ] カメラ本体（バッテリー2本以上）
- [ ] レンズ（標準ズーム＋単焦点 最低2本）
- [ ] SDカード（64GB以上 × 2枚）
- [ ] 三脚 or 一脚
- [ ] NDフィルター（屋外光対策）

### あると強い機材
- [ ] ジンバル（スムーズな動画用）
- [ ] 外付けマイク（環境音収録用）
- [ ] LEDライト1灯（室内の光量補完）
- [ ] レフ板

### サポート品
- [ ] 犬用おやつ（ハンドラーが持参・サロン許可を事前確認）
- [ ] 犬用おもちゃ1〜2点（注目誘導用）
- [ ] タオル（犬が怖がったとき包む用）
