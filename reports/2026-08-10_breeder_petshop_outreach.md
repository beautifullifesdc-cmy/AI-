## 1. なぜブリーダー・ペットショップなのか（狙いの整理）

```
これまで：既存の飼い主（トリミングサロン利用者）にアプローチ
新しい狙い：「これから飼い始める人」の入口に立つ

ブリーダー・ペットショップ = 新しい家族を迎える瞬間に立ち会う存在
   → お迎え日の記念撮影・成長記録の入口として提案できる
   → 早い段階で関係を作れれば、トリミング撮影・Stories撮影への
     長期的な導線にもなる
```

3方良しモデル（`2026-07-13_three_way_revenue_model.md`）と同じ構造が使える：
ブリーダー・ショップに費用負担なし、成果報酬 or 素材提供で還元。

## 2. テレアポ台本（ブリーダー・ペットショップ向け）

### オープニング（10秒）

```
お世話になります、Beautiful Life（ビューティフルライフ）と申します。
突然のお電話失礼いたします。

これから新しい家族を迎えられるお客様向けに、
記念撮影のご案内をさせていただきたく、お電話しました。
少しだけお時間よろしいでしょうか？
```

### 要件説明（30秒以内）

```
私たちは、子犬・子猫をお迎えになったお客様の
「お迎え日」や「成長の記録」を、動画や写真で残すお手伝いをしています。

費用はご利用されるお客様から直接いただく形なので、
御社にご負担いただく費用は一切ありません。

ご案内いただいた分は、売上の一部を還元するか、
撮影した写真・動画を御社のSNS・HP用に無料でお渡しするか、
どちらか選んでいただけます。
```

### クロージング

```
実際に撮影したサンプル動画がありますので、
よろしければ、御社のメールかLINEにお送りしてもよろしいでしょうか？
```

## 4. 送り方の優先順位

```
① 電話番号が確認できている先（約10件）→ 最優先でテレアポ
② 個人ブリーダー・小規模犬舎（HP問い合わせ or メール） → じっくり関係構築
③ チェーン系ペットショップ（コジマ・ペッツファースト等） → 本部交渉が必要な場合あり、
   店舗単位より先に本部確認が無難
```
