## 🕐 Hour 1（0:00〜1:00）セットアップ

### Person A の作業（順番通りに実行）

**① Instagramをプロアカウントに切り替える（5分）**
```
1. Instagramアプリを開く
2. 右下のプロフィールアイコンをタップ
3. 右上「≡」→「設定とアクティビティ」
4. 「アカウント」→「プロアカウントに切り替える」
5. 「クリエイター」を選択
6. カテゴリ:「写真/ビデオサービス」を選択
7. 完了
```

**② CanvaにInstagramを連携する（5分）**
```
1. canva.com を開く（PC推奨）
2. 「デザインを作成」→「Instagram投稿」
3. デザイン画面で右上「共有」をクリック
4. 「もっと見る」→「Instagram」をクリック
5. 「Instagramにサインイン」→ ログインして連携完了
6. 以降すべての投稿をここから予約できるようになる
```

**③ Canvaにブランドカラーを登録する（5分）**
```
1. Canvaの左サイドバー「ブランドキット」をクリック
2. 「カラーを追加」で以下3色を登録:
   - ゴールド: #C9A84C（メインカラー）
   - ホワイト: #FAF7F0（背景色）
   - ブラウン: #3D2B1F（テキスト色）
3. 以降デザイン時にワンクリックで使えるようになる
```
