## テキストリール・カルーセルを使わないSNS拡散戦略

### ▼ アルゴリズムの大前提（Data Analyst調査）

| シグナル | アルゴリズムへの影響力 |
|---------|----------------------|
| **1位：シェア（DM送信）** | いいねの3〜5倍の重み |
| **2位：視聴時間（完全視聴率）** | 尺が短いほど有利 |
| **3位：保存** | いいねより格段に重い |
| 4位：コメント | 深さが重要（「かわいい」は効果薄） |
| 5位：いいね | 最も軽いシグナル |

**→ 結論：「いいねを増やす」より「保存・シェアされる動画を作る」が正解。**

### ▼ 最適なReels尺（データ）

- **7〜15秒：完全視聴率74%（最高）**← Beautiful Lifeはここに全集中
- 15〜30秒：62%
- 30〜60秒：49%
- 60秒超：非推奨

## 使うコンテンツフォーマット TOP3

### 【フォーマット①】感情トリガー型シネマリール（最重要）

既存のサンプルリールを**「冒頭3秒を感動シーンにして再編集」**して投稿。

```
編集手順：
1. 最も感動的な瞬間（犬が振り返る・目が合う・走る）を冒頭3秒に配置
2. トレンド音楽を乗せる（曲のサビが感動ピークと合わせる）
3. テキスト一切なし、7〜15秒でカット
4. 「友達の犬好きに送ってみて🎬」をキャプションに入れる
```

**今すぐできる。新しい素材不要。既存リールを再編集するだけ。**

---

### 【フォーマット②】Before/After感情リール（バズ量産型）

スマホ写真（誰でも撮れる普通の写真）→Beautiful Lifeの映像に切り替える。

```
構成：
・スマホ普通写真 2秒 → Beautiful Lifeのシネマ映像 10秒
・切り替えのタイミングを曲のドロップに合わせる
・テキストなし。映像の差が全てを語る
```

**「自分の犬でもやりたい」という保存・シェア欲求を直撃する。**

---

### 【フォーマット③】ループ動画（再生数爆上げ型）

犬が走ってフレームアウト→また走り込む7〜10秒の無限ループ。

```
編集ツール：CapCut（無料）でループ設定
効果：1視聴が「2〜3回再生」としてカウントされ、アルゴリズムに人気動画と認識される
```
