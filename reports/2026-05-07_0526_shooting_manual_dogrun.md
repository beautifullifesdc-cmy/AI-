## ▼ カメラ設定（目的別）

### iPhone設定

| 目的 | 設定 |
|------|------|
| **Reelsメイン** | 4K / 60fps・HDRオフ・AE/AFロック必須 |
| **スローモーション** | 1080p / 240fps（晴天・日向限定） |
| **手ブレ対策** | アクションモードON（iPhone 14以降・晴天専用） |
| **Cinematic Mode** | 犬がゆっくり歩くシーンのみON（走るシーンは非推奨） |

> **重要**: HDR動画はOFFにする。Instagram投稿時に色が崩れる。

### ミラーレス一眼設定

| 目的 | F値 | SS | ISO | ND |
|------|-----|----|-----|----|
| **Reels用（4K/60fps）** | f/4〜5.6 | 1/120 | 100〜400 | ND8〜16 |
| **スロー（1080p/120fps）** | f/5.6〜8 | 1/240 | 100〜400 | ND16〜32 |
| **YouTube用（4K/24fps）** | f/2.8〜4 | 1/50 | 100〜400 | ND4〜8 |

> **AF設定**: 動物瞳AF ON・追従感度最大・ワイドゾーン

## ▼ 光の使い方（5月屋外）

### 時間帯別

| 時間帯 | 光の特性 | 何をすべきか |
|--------|---------|------------|
| **7:00〜9:00** | 低角度・暖色・サイドライト | **最重要時間帯。S級ショットを集中投入** |
| **10:00〜13:00** | 真上からの強光・パンダ影 | 木陰へ移動・白い反射板を地面に置く |
| **14:00〜16:00** | 斜め順光・安定 | 確実に使える素材の追加収集 |
| **16:30〜18:00** | **黄金時間** | 最高のポートフォリオ映像・シルエットショット |

### 光の状況別対応

```
晴天直射日光（正午前後）
  → 木陰に移動
  → 白いカラーボード（Daiso）を地面に置いて反射板に
  → 240fps（スロー）は光量が最大のこの時間帯に使い切る

逆光（太陽が背後）
  → 露出を+1〜+1.5EV補正（顔にAEロック）
  → 毛並みがリムライトで光る→Beautiful Lifeのブランドイメージに直結

曇り・薄曇り
  → 表情クローズアップ（S-2・S-3）の最適条件
  → Cinematic Mode解禁

黄金時間（朝・夕）
  → ホワイトバランスを「曇り」（5600〜6500K）に固定してウォームに
  → シルエットショット（A-7）を試す
```

## ▼ 撮影テクニック

### 構えの基本
- **必ず犬の目線の高さ以下に下がる**（膝立ち・しゃがみ・腹ばい）
- 立ったまま見下ろして撮らない——見物人の目線になり感情的つながりが生まれない

### パンニング（疾走感を出す）
1. 両脇を体に密着・腰から上をターンテーブルのように水平回転
2. 犬の動きより**わずかに先を向いた状態**でカメラを起動し、犬に追いつかせる感覚
3. 撮影後も追跡を**1〜2秒続ける**（フォロースルー）—— 途中で止めるとブレる

### 録画タイミング
- **早く開始し、遅く止める**
- 5〜10秒長めに回し続ける
- 「来るかもしれない」と思ったら**2〜3秒早く**録画開始

### 1カットの長さ
- 意識的に**3〜7秒で一度止め、アングルを変えて次のショットへ**
- 同じアングルを10秒以上回し続けない

## ▼ 犬をカメラ目線にさせる5つの方法

| 方法 | 手順 | 効果 |
|------|------|------|
| **① 変な音作戦** | キュッキュッ・舌打ち・リップロールをレンズの真上で鳴らす | 即効性最強。使いすぎると慣れるので「ここぞ」の一回に絞る |
| **② おやつ作戦** | カメラにおやつを輪ゴムで固定→飼い主に確認後、匂いを嗅がせてから離れる | 自然に鼻ひくひく×目線が揃う |
| **③ 飼い主をカメラ後ろに立たせる** | 飼い主がカメラの真後ろから犬を呼ぶ | 犬は飼い主を見ているが映像上はカメラ目線になる |
| **④ 待ちの撮影** | カメラを構えてその場に静止して待つ | 好奇心旺盛な犬が自分から近づいてくる |
| **⑤ 関係構築5分** | 最初はカメラをしまって犬と接触→信頼が生まれてから撮影開始 | この5分が1時間分の素材の質を決める |

## ▼ よくある失敗 NG集

| NG | なぜダメか | 対策 |
|----|-----------|------|
| 立ったまま撮る | 見物人目線になる | 必ずしゃがむ |
| ズームしすぎ | 手ブレが増幅される | 35〜85mm相当まで。iPhoneは1x〜2xまで |
| 完璧な瞬間を待ちすぎる | 最高の瞬間を何度も見送る | 「来るかも」で即録画開始 |
| 逆光を避けすぎる | 全カットが平坦な証明写真になる | 朝・夕は積極的に逆光を使う |
| 1カットを長く回しすぎる | 編集で使える部分が3秒しかない | 3〜7秒でアングルを変える |
| AFが別の犬に持っていかれる | 主役がボケる | 対象犬をタップしてロック・外れたら即再タップ |
