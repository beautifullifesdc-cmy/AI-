## 1. 電話とDMの決定的な違い

DMは読み飛ばされても実害がないが、電話は**最初の10秒で切られるかどうかが決まる**。
これまでの台本（`2026-07-09_telephone_outreach_pivot.md`）は方向性は正しいが、
「新モデル」の説明が入っていないため、今のタイミングでアップデートする。

## 2. 改訂版 テレアポ台本

### オープニング（10秒・要件を先に言い切る）

```
お世話になります、Beautiful Life（ビューティフルライフ）と申します。
突然のお電話失礼いたします。

サロンさま向けに、費用のご負担なしで導入いただける
撮影サービスのご案内でお電話しました。少しだけお時間よろしいでしょうか？
```

→ 「費用のご負担なし」を10秒以内に入れるのが今回の改訂ポイント。
　 ここで relief（安心）が生まれ、切られにくくなる。

### 要件説明（30秒以内）

```
ありがとうございます。

トリミングにいらっしゃる飼い主さまに、施術の前後で
撮影のオプションをご案内するサービスです。

費用は撮影を希望される飼い主さまから直接いただく形なので、
サロンさまのご負担は一切ありません。

ご利用いただいた分は、売上の一部を還元するか、
撮影した写真・動画をサロンさま用に無料でお渡しするか、
どちらか選んでいただけます。
```

### クロージング（サンプル送付の許可だけをもらう）

```
実際に撮影したサンプル動画がありますので、
よろしければ、お店のメールかLINEにお送りしても良いでしょうか？
```

→ **電話の目的はここまで。** その場で契約や詳細を詰めようとしない。
　 「サンプルを送る許可」が取れれば電話としては成功。

### 断られた場合

```
かしこまりました。お忙しいところ失礼いたしました。
もしまたご興味持たれましたら、いつでもご連絡ください。
```

## 3. なぜこれが「今」効くと考えるか

- 訪問の転換率5%（`2026-07-20`報告）は、対面で「無料」「リスクゼロ」を口頭で伝えられたから
  成立している可能性が高い。電話はこの"口頭説明の強み"を再現できる数少ないチャネル
- DM/HPフォームは文章で「費用ゼロ」を伝えても、警戒されて読み流されている可能性がある。
  電話なら疑問をその場で解消できる
