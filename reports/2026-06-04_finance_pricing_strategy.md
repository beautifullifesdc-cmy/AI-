## 4. 価格設定の哲学（なぜ安くしてはいけないか）

### 「安い＝信頼できない」のペット業界の現実
- 愛犬の動画は「感情商品」。安い映像制作を頼む人は"映像の価値"を信じていない
- ¥35,000を払う飼い主より、¥60,000を払う飼い主の方が「仕上がりへの期待値と満足度」が高い
- 高単価は"選ばれた実感"を生む → リピート・紹介につながる

### 「安い今のうちに客を取ろう」が長期的に損な理由
```
安い価格で契約 → その価格が相場として認識される
→「なんで値上がりしたの？」と言われる → 解約 or 値下げ圧力
→ 正しい価格に戻せなくなる
```

**正解：最初からサンプルに自信が持てる価格で出す。**
サンプル（¥10,000）→ 正規（¥60,000）の落差は"段階"として自然に伝わる。

### 価格のアンカリング（提案時のトーク設計）
```
✕「¥35,000でどうですか」（安いと思われる）

◎「通常の動画制作会社さんだと¥150,000〜になるんですが、
   私たちは月額のパートナーとしてお付き合いしたいので、
   撮影単体なら¥60,000、月額でお付き合いいただくなら
   撮影込みで¥59,800〜でご提案させていただいています」
```

→ ¥150,000との比較で¥60,000が"安い"と感じさせる。
