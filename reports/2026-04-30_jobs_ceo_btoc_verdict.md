# CEO Report — Jobs → オーナー｜BtoC戦略の見解

**報告日**: 2026-04-30
**報告者**: Jobs (CEO)
**テーマ**: SNSリール動画メニューのToCへの掲載是非と進め方

---

## Jobs の結論（3行で）

> **「SNS用リール動画」という言葉をToCに使うな。**
> **ToCに売るのではなく、ToCを通じてToBへ届ける設計にしろ。**
> **今フェーズのToCの役割は「実績・口コミ・サロンへの橋渡し」の3つだけだ。**

---

## 問いへの直接回答

### Q：SNSリール動画メニューはToCにも掲載すべきか？

**A：掲載するが、言葉を完全に変える。**

| | BtoB（サロン）向け表現 | BtoC（飼い主）向け表現 |
|-|---------------------|---------------------|
| サービス名 | 「SNS最適化動画制作」 | 「愛犬の思い出ムービー」 |
| 訴求軸 | 集客・フォロワー増加 | 記念・感動・宝物 |
| 価格 | ¥20,000〜（モニター） | 今フェーズは無料 |
| CTA | 「DMで商談を」 | 「かかりつけサロンに紹介してほしい」 |

同じ動画を作っていても、**相手によって言葉を完全に変える。**
これは「二枚舌」ではなく「正しいコミュニケーション」だ。

## ToCの正しい使い方（フェーズ別）

### 今フェーズ（〜3ヶ月）：ToCは「入口」として使う

```
目的: 実績素材の収集・SNSフォロワー獲得・サロンへの口コミ
方法: 無料撮影（ドッグランイベント・保護犬団体）
売らない: 今は有料化しない。信頼を積む時期

ToCフロー:
無料撮影 → タグ付き投稿 → 飼い主がシェア
  ↓
「かかりつけサロンに教えてほしい」と口頭で伝える
  ↓
サロンオーナーの耳に届く → BtoB商談へ
```

### 次フェーズ（4〜6ヶ月）：ToCを副収益に育てる

```
条件: サンプル動画が10本以上揃ってから
内容: 「愛犬の思い出ムービー」として¥10,000〜で販売開始
対象: 誕生日・お迎え記念日・老犬の記録など感情的な動機がある飼い主
```

## 土曜のドッグランでやるべきこと（具体的に）

### やること
```
① 無料で犬の写真・動画を撮る（サービスを「売らない」）
② 「Instagramでタグ付けしていいですか？」と許可を取る
③ 撮影後に一言だけ添える:

「もしかかりつけのトリミングサロンがあれば、
 こういうサービスをやっていると教えてもらえると嬉しいです。
 Beautiful Lifeというサービスです。」

それだけでいい。売り込まない。
```

### やらないこと
```
❌ 「うちのサービスはこうで、料金はこうで...」の説明
❌ その場で契約・金銭のやり取り
❌ 「SNS運用します」という説明（飼い主には響かない）
```

### 保護犬ボランティア団体への提案
```
「保護犬の子たちを映画クオリティの映像で紹介して、
 里親を増やすお手伝いをしたいです。
 費用は一切いただきません。」

→ これだけ。シンプルに。
→ 相手が興味を持ったら連絡先（Instagram）を交換する。
→ 詳細は後日。今日は「関係性を作る」だけでいい。
```

```
❌ ToCの「思い出」系コピー
```

## ▼ 潜在リスク

1. **ToCとToBのメッセージが混在すると両方に刺さらなくなる**
   → Instagramは1つだが「ToCへの投稿」と「ToBへの投稿」を曜日で分けることで解決できる（月・水・金=感情系ToBtoC、火・木=教育系BtoB）

2. **無料撮影を続けすぎると「無料でやってくれる人」という印象が固定する**
   → 今フェーズは意図的に無料で信頼を積んでいると自分で認識しておく。3ヶ月後に有料化する時期を今から決めておく

3. **ToCの飼い主が「サロンに伝えてくれる」保証はどこにもない**
   → 口コミだけに頼らず、ToBへの直接営業も並行して行うこと

## ▼ 潜在機会

1. **土曜のドッグランが「ポートフォリオ制作の場」になる**
   → うまくいけばその日のうちにサンプル素材が10枚以上揃う。これがBtoB営業の最強の武器になる

2. **保護犬団体との連携が「社会貢献ブランド」を作る**
   → 「Beautiful Lifeは保護犬の里親増加にも貢献している」という文脈が、サロンオーナーの「このサービスを使いたい」という感情を加速させる

3. **飼い主→サロン紹介ルートは、営業コストがゼロ**
   → 成立すれば最強の口コミ営業になる。土曜の1日で種を10個以上まける
