## ドッグランの本質的ポジション

```
トリミングサロン（1対1の個室）
       ↕
Beautiful Life
       ↕
ドッグラン（コミュニティハブ・複数人に同時リーチ）
```

ドッグランは「同時に複数の犬オーナーが集まる唯一の場所」。
イベント出店（くろすの森モデル）の常設版として機能する。

---

## 協業モデル 全体図

### モデル①：送客エコシステム（最重要・オーナー案の具体化）

```
[ドッグラン]
  会員に「提携トリミングサロンで撮影できます」と紹介
       ↓
[Beautiful Life]
  ドッグランで映像を撮り → サンプルを見せる → サロンへ誘導
       ↓
[トリミングサロン]
  新規顧客が来店 → Beautiful Lifeへの月額契約を継続する動機になる
```

**各者が得るもの：**

| 立場 | 得るもの |
|------|---------|
| ドッグラン | 会員特典の充実・SNS素材・差別化 |
| トリミングサロン | 新規顧客の定期流入 |
| Beautiful Life | 両者から月額契約 + BtoC撮影料 |
| 犬オーナー | 愛犬の映像という体験価値 |

---

### モデル②：ゼロ円スタート（今すぐできる）

```
「ドッグランで撮らせてもらう代わりに、
  SNS用の動画を毎月無料で提供する」
```

- Beautiful Lifeのコスト：撮影時間のみ
- ドッグランのコスト：ゼロ
- Beautiful Lifeが得るもの：
  - 撮影素材（SNS投稿用）
  - ドッグランの会員へのPR機会
  - 将来の月額契約への入口

**最初の3ヶ月はこのモデルで関係を作り、その後月額契約に移行する。**

---

### モデル③：三者間エコシステム（6ヶ月後の姿）

```
ドッグラン（月額¥20,000）← Beautiful Life → トリミングサロン（月額¥49,800）
     ↑                          ↑                       ↑
  SNS素材を受け取る         中央に立つ              新規顧客を受け取る
  会員特典として活用       コーディネーター           Beautiful Lifeへ感謝
```

このモデルが成立すると：
- ドッグラン1施設 + サロン1施設 = 月¥70,000の安定収益
- 5セット成立 = 月¥350,000

---

### モデル④：「愛犬の一日」パッケージ（高単価・将来の柱）

```
午前：トリミングサロンで施術シーンを撮影
        ↓
午後：ドッグランで遊ぶシーンを撮影
        ↓
完成品：「愛犬の一日」4〜6分のシネマティック動画
```

LovelyGroomingが「室内」に特化しているのに対し、
Beautiful Lifeは「室内×屋外」の両方を撮れる唯一の存在になれる。

**単価：¥50,000〜70,000/頭（プレミアムパッケージ）**

## ドッグランとトリミングサロンの「接続設計」

### 紹介の流れ（標準化）

```
①ドッグランで撮影 or イベント出店
②飼い主に「提携トリミングサロンでも撮れます」と紹介カードを渡す
③トリミングサロンに「来ました」と報告が入る
④月次で「今月は○名ご紹介しました」レポートをサロンに送る
⑤サロンは「ありがとう」という気持ちで月額契約を続ける
```

## ▼ 潜在機会

1. **ドッグランが「常設のイベント出店場所」になる**——くろすの森のような一回性のイベントではなく、毎週末同じ場所に顔を出せる
2. **ドッグランの会員リスト = 最高の見込み客リスト**——施設が持つ顧客基盤をそのまま営業チャネルにできる
3. **「ドッグラン×サロン」パッケージが差別化の決め手になる**——LovelyGroomingにできない「1日完結型の愛犬記録」として圧倒的なポジションを取れる
4. **ドッグランのSNSフォロワーへのリーチ**——タグ付け投稿でドッグランの既存フォロワーに自然に露出できる

## ▼ 潜在リスク

1. **今の段階でドッグランに話に行っても「サンプルがない」**——6/20以降が正しいタイミング。焦らない
2. **三者間の調整は複雑**——A施設とB施設の関係が悪い場合に両方に関わるとトラブルになる可能性
3. **ドッグランは「送客」に積極的でない施設も多い**——まず関係を作り、自然な流れで紹介が生まれる設計が必要
