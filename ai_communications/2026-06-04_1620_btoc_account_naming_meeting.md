## 1. 2アカウントの役割整理（確定）

オーナーの整理を全員で確認し、確定した：

```
本アカ（@beautifullife.movie）= 顧客を把握＋大事にする（既存・信頼）
BtoCアカ                      = 将来の顧客を作る（新規・リーチ）
```

| | 本アカ | BtoCアカ |
|---|--------|---------|
| 役割 | 既存顧客を大事にする・信頼の証拠 | 将来の顧客を作る・リーチ |
| ファネル位置 | 出口（締める） | 入口（広げる） |
| 守るもの | 質（少数だが濃い） | 量＋アルゴリズム |
| 換金方法 | 既存の継続・指名 | 新規受注・代行契約・無料の宣伝媒体 |

→ **この役割分担が固定されたので、何を投稿するか迷わない。**

## 2. ファネルの言い換え：「移行」ではなく「決め手」

オーナー案「BtoC→本アカへの移行」を、より正確な設計に研いだ：

```
✕ BtoCのフォロワーを本アカに引っ越させる（移行）
   → 全員は動かないし、その必要もない

◎ BtoCで惹きつける → 本気の人が本アカを見て確信する（決め手）

   BtoCアカ … 入口（リーチ）「お、この映像いいな」
       ↓ 本気の人だけが見に行く
   本アカ   … 出口（信頼）「ここまでの仕事ができるのか。頼もう」
```

**結論：本アカは引っ越し先ではなく"契約を締める最後の証拠"。**
だから本アカは無理に量を増やさず、今の「質だけ」の路線を守ればいい。

---

## 3. 収益の考え方：「広告収入」ではなく「広告媒体」

オーナーの「広告収入も見込めると嬉しい」に対し、Finance・SNS Managerが整理：

```
✕ 広告"収入"（プラットフォームの再生報酬）
   → 日本では小さく不安定（1万フォロワーでも月数千〜数万円）
   → ここを狙うと"バズるだけの中身"に引っ張られ世界観が崩れる

◎ 広告"媒体"（自分のアカウント＝お金を払わず使える宣伝チャンネル）
   → フォロワー1万 = 毎回タダで1万人に届く自社広告枠
   → 本来は広告費がかかるものを無料で持てる＝これが資産
```

**結論：アカウントの伸びは"再生報酬"ではなく、その媒体力で集めた
「撮影の受注」と「代行契約」で換金する。**

## 4. コンテンツの仕分け（本アカ vs BtoCアカ）

| コンテンツ種類 | 本アカ | BtoCアカ |
|-------------|--------|---------|
| 完成した作品（30秒〜1分） | ◎ | ◎ |
| 映像美のある切り抜き（スロー・逆光） | △ たまに | ◎ |
| Before/After変身 | ✕ | ◎ |
| 撮影の裏側BTS | ✕ | ◎ |
| 共感あるある系 | ✕ | ◎ |

- **完成品は両アカに出してOK**（投稿コストが実質半分・本アカ維持が楽になる）
- トリミングの可愛いカットは「切り抜き量産」ではなく
  **スロー・逆光・音楽込みの"1本の作品"**として出せばBtoCアカに合う
- 切り抜き・BTS・共感系は本アカに出さない（世界観が薄まるため）

## 5. BtoCアカウント名（決定案）

本命：**`beautifullife.pet`**

| 候補 | 路線 | 評価 |
|------|------|------|
| **beautifullife.pet** | 兄弟・王道（犬猫カバー） | ◎ 本命 |
| beautifullife.pets | 〃 複数形 | ◎ |
| beautifullife.daily | 親しみ・継続感 | ○ |
| beautifullife.moment | エモ・作品性 | ○ |
| beautifullife.petfilm | 作品性を残す | ○ |

**本命の理由：**
- `.movie` と並べた時に一目で兄弟と分かる
- `.pet` は犬猫＋将来の他ペット（猫カフェ等）もカバー
- 短く覚えやすく検索されやすい

> 取得不可の場合：`beautifullife.pet_` / `beautifullife_pet` / `beautifullifepet`
> ——本アカと表記が揃うことを最優先。

**表示名（プロフ上部）**：`Beautiful Life｜ペット映像`
→ 「ペット・映像・撮影」を入れて検索にひっかける。
