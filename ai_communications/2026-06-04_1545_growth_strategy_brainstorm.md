## Jobsの初期診断：「3つのうち2つはブレる。1つは武器」

**核心リスク＝ブランドの矛盾。**
```
これまでの旗印：「AIに作れない、生の映像を作品にする」（職人性・プレミアム）
新路線     ：「AIで効率よく量産する」（効率・コモディティ）
→ 同じ看板で両方語ると、プレミアムの価格根拠が崩れる
```

ただし**整理すれば両立する**——というのが今日の結論の出発点。

| 案 | 初期評価 |
|----|---------|
| インスタ/LP代行を"柱"にする | ✕ レッドオーシャン・差別化ゼロ |
| AIで効率制作（裏方） | ◎ ただし「事業」でなく「武器」として |
| AIサロン | △ 2027以降のLayer3にパーク |
| 別アカ量産 | △ オーディエンス・ミスマッチに注意 |
| AIサイト先出し営業 | ◎ 今フェーズ最強の営業ツール候補 |

2. **AIサイトの真意**＝HPなしサロンに現物を見せて受注。**画像はAIと実物の区別がつかない**から動画より有効。サイトを入り口に動画提携へ

## 全エージェントの意見（②AIサイト・①BtoCアカ）

### Aggressive Marketer
**AIデモサイト先出し＝飛び込み営業の概念を変える最強の武器。**
「できます」ではなく「作りました、見てください」で信用ゼロを飛ばす。
`サロン名/Insta → AI草案生成 → 先出し → 月額¥15,000 → 動画へ`。先に価値を渡す者が勝つ。

### SNS Manager
BtoCアカは**「何を発信するか」で全決まる**。
- ✕ 可愛い犬を並べるだけ→"バズ職人"の証明止まり
- ◎ **映像美でバズる**→「これ誰が撮った？」が受注起点
英語タグで海外バズも。**BtoC直接撮影¥15,000〜をメニュー化**して直受注の導線を。

### Business Strategist
2案とも**「柱」にすると✕、「ツール」にすると最強**。
弱点指摘：「フォロワー増＝代行実績」は完全イコールでない。
（BtoC犬好き向けが作れる ≠ 店に客を呼べるコンテンツが作れる）
橋渡し策：**BtoCアカでサロンをタグ付け→「その投稿で問い合わせが来た」実績**を作る＝本当の代行証明。

### Finance
- AIサイト：1サロン最大 月¥99,800（サイト¥15-20k＋動画¥29.8-79.8k）。10件で月約¥998,000。**即効性高**
- BtoCアカ：フォロワー1万到達後に 月約¥175,000（直撮影＋代行）。**中期投資（6-12ヶ月）**
→ 評価：AIサイトが即効・本業との相乗効果大。BtoCは中期で育てる。

### Creative Director
AIは**「隠す」より「言わなくていい環境」**を作れ（CADや美容シザーと同じ、成果物で語る）。
バレ対策：**完成後にオーナーと一緒に編集体験**させ"うちのサイト"化。
差別化軸：**「撮影者が作るから写真が映えるサイト」**——デザイン会社にもAIにも真似できない。

### Reality Checker
両案とも**やる前に決めること**がある。
- BtoCアカ：週10-15hの工数→**サロン5社契約後が現実的**
- AIサイト：受注後の**サーバー/ドメイン/更新の管理コスト**→**まず3施設だけ試作**して反応と管理負荷を測る

### Biz Dev
**2案の"組み合わせ"に最大の可能性。3段ロケット：**
```
HPなしサロン発見 → AIデモサイト先出し（入口・高成約）
→ 月額サイト管理 → 「実は撮影も」動画サンプル提示
→ 動画月額契約（高単価・継続）
→ BtoCアカでそのサロンを紹介（新規客＋解約防止）
```
成立時、Beautiful Lifeは**「映像×Web×SNS」を束ねるプロデューサー**になる。
