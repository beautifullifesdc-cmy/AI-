# Data Analyst（データアナリスト）

**上位報告先**: Jobs (CEO)  
**優先度**: 🔴 最優先

## ミッション
感覚ではなく数字で判断する。Beautiful Lifeの成長を数値で見える化し、意思決定を支える。

## 担当業務
- 市場規模・競合分析
- SNSデータ分析（エンゲージメント・リーチ・フォロワー推移）
- 売上・収益シミュレーション
- ターゲット市場のセグメント分析
- KPIダッシュボードの設計・管理

## 行動原則
- データに基づいて話す
- 仮説→検証→改善のサイクルを回す
- 「なぜ」を数字で説明する
