## 3. 厳しめ想定の月次PL

「契約が全然伸びない最悪に近い月」を想定：

```
【売上】
  BtoB月額サブスク   1社 × ¥29,800      = ¥29,800
  BtoBサロン撮影     2件 × ¥35,000      = ¥70,000
  BtoC個人撮影       0件                = ¥0
  サイト管理         0社                = ¥0
  ──────────────────────────────
  売上合計                              = ¥99,800

【変動費】
  交通費 ¥4,000 ＋ 消耗品 ¥2,000        = ¥6,000

  粗利（売上総利益）                    = ¥93,800

【固定費】                              = ¥46,500

【営業利益（人件費前）】               = ¥47,300
```

> **厳しめでも人件費前で月+¥47,300。** つまり構造的には赤字になりにくい。
> ただしこれは「オーナーの労働を0円とした場合」。**実態の利益＝この¥47,300から
> 自分の給料を引いた残り。** だから次のステップで人件費を必ず入れる。

## 4. 損益分岐点（人件費前）

```
固定費 ¥46,500 ÷ 撮影1件の粗利 約¥33,000 ≒ 1.4件

→ 月2件の撮影で固定費を回収。
→ 月3件以上で「人件費に回せるお金」が生まれ始める。
```

**最初の安全ライン＝月2〜3件の撮影 or サブスク1〜2社。**
ここを下回る月が続くなら、価格か営業のどちらかを見直す合図。

## 7. Finance からの注意点（厳しめ目線）

1. **一番の見落としは「機材の減価償却」と「自分の時給」** ——どちらも現金が出ていかないので利益を錯覚しやすい。必ずコストとして意識する
2. **単発撮影だけだと毎月ゼロから営業し直し** ——サブスクの比率を上げるほど経営は安定する
3. **広告費・AIツールは"増やせば売上が増える"わけではない** ——固定費は厳しめに抑え、利益が出てから増やす
4. **次のステップ：人件費を入れて"本当の利益"を見る** ——月の自分の稼働時間 × 希望時給を算入し、黒字が残るか確認する
